# AmazingVisual website

Фиолетовый адаптивный лендинг AmazingVisual без внешних изображений, с демонстрационным окном регистрации/входа.

## Файлы
- `index.html` — структура сайта и формы.
- `style.css` — дизайн, адаптивность и анимации.
- `script.js` — модальные окна и клиентская проверка полей.

## Проверка
Открой `index.html` в браузере. Для Google Fonts требуется интернет; без него сайт использует запасные системные шрифты.

## GitHub Pages
Загрузи все файлы в корень репозитория `k4pit00/amazing_visuals`. Затем Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Ожидаемый адрес: https://k4pit00.github.io/amazing_visuals/

## Важно: регистрация пока демонстрационная
Форма проверяет ник (не более 16 символов), почту, пароль (минимум 8 символов) и совпадение подтверждения. Данные не отправляются и не сохраняются. Для реальных аккаунтов, безопасного хранения паролей, входа в DLL и списка игроков нужен сервер/API и база данных. Не подключай реальную авторизацию только на клиентском JavaScript.
